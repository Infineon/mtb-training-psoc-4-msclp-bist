    PSOC™ 4 E3 training - CAPSENSE™ built-in self-test (BIST)¶

    This training provides an introduction to the built-in self-test capabilities of the PSOC™ 4 CAPSENSE™ middleware. The training includes hands-on labs, providing a great starting point to getting familiar with using these tests.

    Device family¶

    • PSOC™ 4

    How to use this training?¶

    1. Download the training content.
    2. Watch the video or review the presentation at your own pace.
    3. Follow the step-by-step instructions in the training manual during the hands-on sections.
    4. Use the provided source files if needed to verify the solution.

    Training level¶

    • E3: Advanced

    Pre-requisites¶

    Training¶

    • PSOC™ 4 CAPSENSE™ using PSOC™ 4000T and PSOC™ 4100T Plus training

    Tools (see training manual for versions and installation instructions)¶

    • ModusToolbox™ with Eclipse IDE
    • ModusToolbox™ Programming tools
    • ModusToolbox™ CAPSENSE™ and Multi-Sense Pack

    See training content for versions and instructions.

    Hardware¶

    • CY8CPROTO-040T
    • CY8CPROTO-041TP

    Duration¶

    • ~90 min video with hands-on labs

    Agenda¶

    1. Introduction to the CAPSENSE™ middleware self test library functions
    2. When to run CAPSENSE™ self tests
    3. Description of the CAPSENSE™ self tests available
    4. Lab 1: Executing the built-in self-tests
    5. Lab 2: Executing the built-in self-tests periodically during runtime

    Expected outcome¶

    • Get hands-on experience with the CAPSENSE™ middleware built-in self-tests
    • Get familiar with PSOC™ 4 hardware and software ecosystem
    • Dive deeper with challenges included for all labs
